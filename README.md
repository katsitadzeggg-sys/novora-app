# Novora

Novora-ს ავეჯის კონსტრუქტორი: შოურუმის კიოსკი, ოსტატის სამუშაო ინსტრუმენტი და კორპორატიული რეჟიმი.

## ახლანდელი ვერსია (პროტოტიპი)
`index.html` — ერთფაილიანი ვებ-აპლიკაცია (Three.js):
- 7 ნაბიჯი: კლიენტი → ავეჯი → ზომები → მასალა → ფურნიტურა → დეტალირება → რასკროი
- AGT-ის მასალები: LAM, 3P PET, Trendy, Supramat, შეღებილი MDF; პოპულარული ფერები გამოყოფილია
- დეტალირება მმ-ში, კრომკა, ფურნიტურა (ეკონომი / Hettich / Blum), სერვისები
- რასკროი: გილიოტინური განლაგება ფილებზე (ხერხი 4 მმ, კიდე 10 მმ, ბოჭკოს მიმართულება)
- სახერხში გაგზავნა: ტექსტი + CSV (L1 L2 W1 W2)

## გეგმა
1. საფუძველი: React + Three.js, Supabase (ოსტატები, კლიენტები, პროექტები, ფოტოები), შოურუმის და ოსტატის რეჟიმები, Windows (Tauri) და Android (Capacitor)
2. ბიზნესი: Novora-ს კატალოგი და ფასები, PDF შეთავაზება, ოსტატის გამოწერა (TBC/BOG), საჯარო გვერდი და გალერეა
3. სივრცე: ოთახის ფოტო ფონად, AR (ARCore/ARKit), LiDAR გაზომვა, ვიდეო, iOS
4. კომპანიები: დიდი ეკრანი, რამდენიმე ოთახის პროექტი
